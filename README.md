# 📱 App 3 Vistas (Flutter)

Aplicación móvil desarrollada en **Flutter** que implementa una interfaz de usuario con **tres vistas o pantallas** diferenciadas para la gestión y visualización de información.

---

## 📋 Descripción

Este proyecto fue desarrollado como una aplicación de práctica para implementar navegación entre múltiples pantallas en Flutter. Permite al usuario interactuar con diferentes secciones de la aplicación de forma fluida.

---
